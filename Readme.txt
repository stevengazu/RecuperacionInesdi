Construir las imágenes: 
Desde el directorio raíz de tu proyecto (donde están Dockerfile y docker-compose.yml), ejecuta:

		docker-compose build

Iniciar los servicios: 
	Inicia los contenedores con:
						docker-compose up

Acceder a la aplicación: Abre un navegador o usa Postman para acceder a tu aplicación en 	
http://localhost:3000.
